# Reglas de MateArte

- Queda prohibido escribir el carácter Unicode U+00B7 en respuestas, títulos, documentos y textos de interfaz.
- En componentes de interfaz nuevos o modificados, queda prohibido usar elementos HTML \`<span>\` y \`<p>\`. Elegir elementos semánticos según la función del contenido.
- Quedan prohibidos los microtítulos decorativos tipo eyebrow encima de los títulos de las vistas, junto con las clases CSS que los implementen.
- Mantener los KPI de Gestión alineados con las tarjetas del Inicio: jerarquía clara, valores grandes y colores con significado.
- En ninguna vista usar bordes ni líneas laterales decorativas en KPI, tarjetas, paneles o contenedores. Diferenciar sus estados y separar secciones mediante fondo, espacio, tipografía y color.
